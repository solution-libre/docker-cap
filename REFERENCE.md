# Reference

## Environment variables

| Name                      | Description                        | Default value        |
| ------------------------- | ---------------------------------- | -------------------- |
| `HOSTNAME`                | The Cap hostname                   | `captcha.domain.tld` |
| `CAP_VERSION`             | The Cap image version              | `latest`             |
| `CAP_ADMIN_KEY`           | The Cap admin key                  | `ChangeMeN0w!`       |
| `CAP_CORS_ORIGIN`         | The Cap CORS origin                | `*`                  |
| `CAP_ENABLE_ASSETS_SERVER`| Whether to enable assets server    | `false`              |
| `REDIS_MAX_MEMORY_IN_MB`  | The Redis max memory limit (in MB) | `256`                |
| `REDIS_PASSWORD`          | The Redis password                 | `ChangeMeN0w!`       |
| `REDIS_VERSION`           | The Redis image version            | `8.8.0`              |
